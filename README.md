# DKIC Auto Parts — Catálogo de guayas de freno

Catálogo estático y adaptable a móviles, preparado para GitHub Pages.

## Publicación

El sitio se publica automáticamente mediante GitHub Pages cada vez que se actualiza la rama `main`.

## Desarrollo local

Abra `index.html` directamente o inicie cualquier servidor HTTP estático en esta carpeta.
